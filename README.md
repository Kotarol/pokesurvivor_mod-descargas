# Descargas

Instalador y actualizaciones de un juego privado para Windows.

## Instalar

1. Descarga **[el instalador](https://github.com/Kotarol/pokesurvivor_mod-descargas/releases/latest/download/PokeSurvivor-Setup.exe)**.
2. Ábrelo. Se instala solo (sin permisos de administrador) y crea un acceso
   directo en el escritorio y en el menú Inicio.

Si Windows dice **"Windows protegió su PC"**, pulsa **Más información** y luego
**Ejecutar de todas formas** (sólo al instalarlo).

Se actualiza solo al abrirlo. La partida se guarda en el ordenador y desinstalar
no la borra.
