# PokéSurvivor para Windows

Juego de fans **gratuito y sin ánimo de lucro**: sobrevive a las hordas con tu
compañero Pokémon. Esta es una versión con cambios propios del original
([JPTER78/pokesurvivor](https://github.com/JPTER78/pokesurvivor)), para jugar
como programa de Windows.

## Descargar e instalar

1. Descarga **[PokeSurvivor-Setup.exe](https://github.com/Kotarol/pokesurvivor_mod-descargas/releases/latest/download/PokeSurvivor-Setup.exe)**.
2. Ábrelo. Se instala solo (no pide permisos de administrador) y crea un
   acceso directo **PokéSurvivor** en el escritorio y en el menú Inicio.

**Si Windows dice "Windows protegió su PC":** sale con los programas que no
están firmados con un certificado de pago. Pulsa **Más información** y luego
**Ejecutar de todas formas**. Sólo pasa al instalarlo: las actualizaciones no
lo vuelven a pedir.

## Actualizaciones

El juego se actualiza solo: al abrirlo mira si hay versión nueva y baja sólo
lo que ha cambiado. También puedes pulsar **Buscar actualizaciones** debajo
del menú principal. Sin internet se juega con la versión que tengas.

## Tu partida

- Se guarda en tu ordenador (`%APPDATA%\PokeSurvivor`). Desinstalar el
  programa no la borra.
- En **Ajustes > Cuenta > Copia de la partida** puedes exportarla a un archivo
  y recuperarla en este u otro ordenador (se junta con la que tengas, sin
  perder nada).

## Teclas

| Tecla | Acción |
|---|---|
| `W` `A` `S` `D` / flechas | Moverse |
| `1` `2` `3` `4` | Elegir el movimiento activo |
| `Q` / `E` | Ciclar movimientos |
| `Esc` / `P` | Pausa |
| `F11` o `Alt` + `Intro` | Ventana / pantalla completa |
